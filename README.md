# مكتبة عصام السالم

المكتبة الرقمية لأعمال المهندس عصام السالم — تُقرأ الكتب كاملة داخل الموقع،
وتُنزَّل بصيغة PDF لمن أراد نسخة للاحتفاظ.

## التشغيل

```bash
npm install
npm run ingest    # استخراج النصّ والفهارس من books/*.docx (محلياً فقط)
npm run pdf       # توليد ملفات التنزيل في public/books/ (محلياً فقط)
npm run dev
```

`npm run pdf` يحتاج Microsoft Word (ويندوز) أو LibreOffice، ويتخطّى الملفات
المحدَّثة أصلاً — `npm run pdf -- --force` لإعادة توليدها كلها. شغّل `ingest`
بعده ليُسجَّل حجم كل ملف في بيانات الكتاب (يظهر على زرّ التنزيل).

## إضافة كتاب جديد

### من لوحة الإدارة (`/admin`)

افتح `/admin`. كلمة السرّ الافتراضية `123456` — تُغيَّر من `ADMIN_PASSWORD`
(انظر `.env.example`).

ارفع ملف Word، اختر المعرّف واللون والوسوم، واضغط «إضافة ومعالجة».
اللوحة تستخرج النصّ بنفس نواة `npm run ingest` — فالنتيجة مطابقة
بايتاً ببايت للطريقة اليدوية.

من اللوحة أيضاً: تعديل الوسوم واللون والترتيب وتصحيح العنوان والنبذة،
وحذف كتاب.

**تعمل في وضعين، يُختاران آلياً:**

| | محلياً على جهازك | منشورة على Vercel |
|---|---|---|
| أين تُحفظ | ملفات المشروع مباشرة | إيداع في مستودع GitHub |
| متى تظهر | فوراً (~ثانية) | بعد إعادة نشر Vercel (دقيقة أو دقيقتان) |
| ملف التنزيل | زرّ يولّده من Word | يُرفع جاهزاً مع الكتاب |
| الشرط | لا شيء | `GITHUB_TOKEN` و `GITHUB_REPO` |

**الحذف لا يُفقد ملف Word**: محلياً يُنقل إلى `books/_deleted/` (غير مرفوع
مع المشروع)، وفي وضع المستودع يبقى في تاريخ Git. المولَّد وحده يُمحى
لأنه يُعاد بناؤه من المصدر.

**نصّ الكتاب لا يُحرَّر من اللوحة**: مصدره ملف Word، وتحريره في مكانين
يفتح باب التعارض — لتغييره يُرفع الملف من جديد.

### يدوياً

1. ضع ملف Word في مجلد `books/`.
2. أضف مدخلة في `data/books.registry.json`:
   ```json
   {
     "docx": "اسم الملف.docx",
     "slug": "latin-slug",
     "accent": "#2A2340",
     "tags": ["تاريخ"],
     "order": 9
   }
   ```
3. `npm run ingest && npm run pdf && npm run ingest`
4. راجع `content/review/BOOKS-REVIEW.md` وصحّح ما يلزم عبر `overrides`.

لا يوجد أي خطوة أخرى — ولا قاعدة بيانات.

## ملاحظات تقنية

**المصدر ملفات Word لا PDF.** الـ PDF ناتج طباعة: يُقحم محارف التطويل داخل
الكلمات لضبط المحاذاة، ويكسر الفقرات أسطراً، وقد يعكس رباط «لام-ألف»
(`الله` ← `هللا`). ملف Word هو النصّ الذي كتبه المؤلف وصحّحه، ويحمل تنسيق
العناوين بنفسه فيُبنى منه الفهرس مباشرة.

**الصفحات مولَّدة**، لأن ملف Word لا يحمل فواصل صفحات: ميزانية ثابتة
(`WORDS_PER_PAGE` في `ingest.mjs`) وكل فصل يبدأ صفحة جديدة. رقم الصفحة مرجع
قراءة داخل الموقع لا مطابقة للورق المطبوع. تغيير الميزانية يغيّر الترقيم،
فيُستحسن تثبيتها.

**ملف التنزيل يُولَّد من نفس ملف Word** لا من ملفات PDF القديمة — تلك تحمل
الأخطاء التي صحّحها المؤلف، وما ينزّله الزائر يجب أن يطابق ما يقرأه هنا.

**TypeScript مثبّت على الإصدار 5** — الإصدار 7 غير مدعوم من Next.js 15 ويُعطّل
اختصارات المسارات (`@/`) بصمت.

**البحث كلّه في المتصفّح.** لا خادم بحث ولا خدمة خارجية: كل كتاب يُصدَّر
فهرساً ثابتاً في `/search-index/<slug>` (مصفوفات `[صفحة، نوع، نصّ]`)، ولا
يُنزَّل شيء منها حتى يكتب الزائر أوّل حرف في صفحة البحث. المكتبة كلّها ~٢.٢
م.ب قبل الضغط، والمطابقة عليها بعد التطبيع تستغرق أجزاء من الثانية — أرخص
من بناء فهرس مقلوب وشحنه وصيانته، وأخفّ أثراً على من لا يبحث أصلاً. لا
يُرسَل ما يبحث عنه أحد إلى أي مكان.

المطابقة تُطبّع الهمزات والتاء المربوطة والألف المقصورة والتشكيل والأرقام
العربية-الهندية، لكنّ التظليل يقع على النصّ الأصلي كما كتبه المؤلف — لأن
`normalizeWithMap` تحتفظ بموضع كل محرف. وتُطلب كل كلمات البحث في فقرة
واحدة؛ فإن لم تجتمع في المكتبة كلّها يُخفَّف الشرط ويُصرَّح بذلك للقارئ.

**ما يخصّ الزائر يبقى عنده.** موضع القراءة والعلامات المرجعية في
`localStorage` وحده — لا حساب ولا خادم ولا تتبّع. صفحة «رفّي» تجمعهما،
وهي `noindex` لأنها تختلف من متصفّح لآخر.

**نواة استخراج واحدة.** `src/lib/ingest/core.mjs` تأخذ بايتات ملف Word
وتُعيد كائنات — لا تقرأ من القرص ولا تكتب عليه. يستوردها الطرفان:
`scripts/ingest.mjs` (يقرأ `books/` ويكتب `content/`) ولوحة الإدارة
(تعالج ملفاً مرفوعاً في الذاكرة). خطّ معالجة واحد لا اثنان، فالكتاب
المضاف من اللوحة يمرّ بنفس الشيفرة التي مرّ بها كل كتاب في المكتبة.

**اللوحة تُنتج تغييرات لا تكتب مباشرة.** كل عملية تُترجم إلى مجموعة
«مسار ← محتوى»، ويطبّقها المخزن: على القرص محلياً (كتابة ذرّية، ملف
مؤقّت ثم `rename`)، أو في إيداع واحد على GitHub عبر Git Data API.
الإيداع واحد لا خمسة — إضافة كتاب تلمس خمسة ملفات، وخمسة إيداعات
تعني خمس عمليات نشر وحالة وسيطة مكسورة بينها.

**الملفات الكبيرة تُرفع مقاطع.** Vercel ترفض أي طلب جسمه أكبر من
٤.٥ م.ب، وأكبر كتاب في المكتبة ٤.٧٩ م.ب. فالمتصفّح يقسّم الملف ويرسل
كل مقطع في طلب مستقلّ، ويحتفظ هو بالمراجع ليرسلها كلها عند الحفظ —
لأن كل طلب على Vercel قد يصل نسخة مختلفة من الدالة، فلا ذاكرة مشتركة
بينها والطرف الوحيد الذي يرى الرفع كاملاً هو المتصفّح.

**اللوحة تقرأ من المصدر لا من النسخة المنشورة.** في وضع المستودع
تُقرأ حالة المكتبة من GitHub مباشرة، لأن نسخة Vercel قد تكون أقدم من
آخر حفظ (النشر يستغرق دقيقة) — والبناء على نسخة قديمة يمحو تعديلاً
سابقاً.

**الجلسة كوكي موقَّع** بـ HMAC-SHA256 — لا مخزن جلسات ولا قاعدة
مستخدمين، فالمستخدم واحد. كلمة السرّ تُقارن بزمن ثابت، والدخول محدود
بثماني محاولات كل خمس دقائق. صفحات اللوحة `noindex`، والحماية الفعلية
في التحقّق على الخادم لا في خفاء الرابط.

## الاستضافة

الموقع العامّ ثابت بالكامل (SSG) وينشر على Vercel Free Tier بلا أي
تكلفة أو خدمة خارجية.

**لوحة الإدارة تعمل على Vercel أيضاً.** نظام الملفات هناك للقراءة فقط،
فبدل الكتابة عليه تودع اللوحة التغيير في المستودع، وتلتقطه Vercel
وتعيد النشر. لا قاعدة بيانات ولا تخزين خارجي ولا تكلفة إضافية —
وتاريخ Git يصير سجلّ التغييرات.

للتفعيل، في `Project → Settings → Environment Variables`:

| المتغيّر | القيمة |
|---|---|
| `ADMIN_PASSWORD` | كلمة سرّ قويّة — **لا تترك الافتراضية على الإنترنت** |
| `ADMIN_SECRET` | سلسلة عشوائية طويلة |
| `GITHUB_TOKEN` | رمز fine-grained بصلاحية `Contents: Read and write` |
| `GITHUB_REPO` | `owner/repo` |
| `GITHUB_BRANCH` | الفرع المنشور (اختياري، الافتراضي `main`) |

ثم أعد النشر (Redeploy) ليقرأ المشروع المتغيّرات الجديدة. إن نقص شيء
منها عرضت اللوحة صفحة تشرح ما ينقص بدل أن تفشل بصمت.

**ما يبقى محلياً:** توليد ملفات PDF يحتاج Word أو LibreOffice مثبّتاً،
فيغيب زرّه على Vercel. البديل: ارفع ملف PDF جاهزاً مع الكتاب من نموذج
الإضافة، أو ولّدها محلياً بـ `npm run pdf` وارفعها. وكذلك تقرير
المراجعة `content/review/BOOKS-REVIEW.md` يُنعشه `npm run ingest`
محلياً — اللوحة لا تلمسه.
